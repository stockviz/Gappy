# Momentum Strategies: Some Bootstrap Tests
**Authors:** G. Andrew Karolyi, Bong-Chan Kho
**Year:** 2004
**Journal/Venue:** Journal of Empirical Finance

## Problem statement

Karolyi and Kho ask whether the profitability of Jegadeesh-Titman momentum strategies can be generated by conventional return processes once one allows for the features that simple textbook nulls omit: time-varying expected returns, factor structure, serial dependence, cross-serial dependence, and conditional heteroskedasticity. The target is not a reduced-form alpha estimate, but a properly simulated null distribution for momentum profits.

## Approach (short)

The paper estimates several stock-return models, bootstraps from those estimated nulls, and re-runs standard momentum strategies on the simulated data. The baseline trading rule is the usual `J`-month formation / `K`-month holding winner-minus-loser portfolio:

1. rank stocks on past `J`-month returns;
2. buy the top decile and short the bottom decile;
3. hold for `K` months with overlapping portfolios and monthly rebalancing.

The models range from a random walk with drift to conditional Fama-French specifications with AR terms, lagged market terms, GARCH-style volatility adjustment, and macro/market instruments. Simulated profits are then decomposed into contributions from intercepts, factor loadings, and conditioning information.

## Approach (detailed)

### 1. Define the momentum trade exactly

Each month, the paper forms equal-weighted decile portfolios from past `J`-month returns and holds them for `K` months. A `J`-month/`K`-month strategy therefore means:

- rank on returns from the prior `J` months;
- define `P1` as losers and `P10` as winners;
- hold `P10 - P1` for `K` months;
- rebalance monthly so the live strategy is an average of overlapping vintages.

This is the object whose realized return distribution the bootstrap must explain.

### 2. Use estimation-based bootstrap rather than pure resampling

The core statistical device is the Freedman-Peters estimation-based bootstrap:

1. estimate a stock-return model on the original panel;
2. recover standardized residuals;
3. resample those residuals with or without replacement;
4. feed them back through the estimated model to generate synthetic return histories;
5. recompute the momentum strategy on each synthetic sample.

This matters because the paper wants a null that preserves the structure implied by a model, not a naive reshuffling of raw returns.

### 3. Estimate a ladder of return-generating models

The null models are deliberately nested.

The random-walk family starts from:

$$
R_{it} = a_i + e_{it},
$$

and then adds:

- own-return autocorrelation via an `AR(1)` term,
- cross-autocorrelation via lagged market return,
- conditional heteroskedasticity via volatility standardization based on a market `GARCH(1,1)` filter,
- lagged conditioning variables.

The factor-model family starts from:

$$
R_{it} = a_i + b_i R_{mt} + c_i SMB_t + d_i HML_t + e_{it},
$$

and adds the same error-structure enrichments:

- own-lagged return,
- lagged market return,
- volatility scaling,
- macro and market instruments.

The conditioning variables follow the Chordia-Shivakumar style logic and include lagged T-bill yield, dividend yield, default spread, term spread, and a January dummy.

### 4. Preserve the null model but vary the resampling scheme

One disputed issue in earlier momentum bootstraps was whether returns should be sampled with replacement or without replacement. Karolyi and Kho run both.

- With replacement is the standard bootstrap and better approximates the empirical distribution.
- Without replacement avoids recycling the same observation across ranking and holding windows, the Jegadeesh-Titman objection.

The paper does not assume one side is automatically right; it shows the result is not rescued by either choice.

### 5. Evaluate the models by simulated momentum profits

For each fitted model and bootstrap design:

1. generate `500` synthetic panels;
2. compute the momentum winner-minus-loser return for the usual `J/K` combinations;
3. compare the simulated mean and t-statistic with the realized one;
4. record simulated p-values as the fraction of bootstrap worlds with profits at least as large as the data.

The key question is not whether the null can generate some positive continuation. It is whether it can generate momentum spreads as large as those in the data.

### 6. Decompose simulated profits into intercept, factor, and conditioning pieces

The main methodological addition is the decomposition analysis. Once the Fama-French model is estimated, the bootstrap can be re-run using:

- intercepts only,
- intercepts plus factor loadings,
- the full model including conditioning information.

That lets the authors ask which component explains the simulated momentum return. The decomposition is especially aimed at the conditional-expected-return view:

- if intercepts alone explain little, pure cross-sectional mean-return dispersion is not enough;
- if factor loadings help, common risk matters;
- if instruments explain most of the incremental simulated spread, time-varying expected returns are doing the work.

### 7. Main implementation takeaway

The paper finds that even the richer nulls do not replicate the full empirical momentum profits. But the conditional models with market-wide and macro instruments can explain roughly `75%` to `80%` of the spread. So the implementable lesson is subtle:

- unconditional factor models are too weak as nulls;
- conditional expected-return variation matters materially;
- but it still does not fully close the case against momentum as an anomaly.

## Domain of applicability

- **Where it works well:** Evaluating whether a proposed return anomaly can be produced by a structured null with realistic dependence and conditional mean variation.
- **What is implementable:** Estimate conditional stock-return models, bootstrap standardized residuals, and re-run the exact trading rule on synthetic data.
- **Main limitation:** The conclusion depends on the quality of the estimated null; omitted state variables or nonlinearities can still matter.
- **Why the paper matters:** It turns the momentum debate into a disciplined simulation question rather than a loose comparison of alphas.
