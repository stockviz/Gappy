# 1. Metadata

- **Title:** Portfolios from Sorts
- **Author(s):** Robert Almgren, Neil Chriss
- **Year:** 2005
- **Journal/Venue:** Working paper / manuscript

# 2. Problem statement

The paper studies portfolio construction when the investor knows only ordinal information about expected returns, not cardinal expected-return estimates. Given a covariance matrix $V$ and a complete or partial sort of assets by expected return, the problem is to define and compute “optimal” portfolios that respect all return vectors consistent with the sort. The precise question is how to replace Markowitz’s point estimate $r$ by an order cone $Q$ of admissible expected return vectors while preserving a meaningful efficient set.

# 3. Approach (short)

The method is convex analysis on a cone of consistent return vectors. Almgren and Chriss define a preference relation: among portfolios with the same risk, prefer the one whose relevant component has weakly higher expected return for every $r\in Q$. They characterize the efficient set for a single complete sort as exactly those portfolios that are Markowitz-optimal for some $r\in Q$ with zero sum, then select a unique portfolio by maximizing a centroid functional over that efficient set. The novelty is the preference relation over an order cone, not a new quadratic optimizer.

# 4. Approach (detailed)

1. **Sort information as a cone of admissible means**

   For a single complete sort $S_1,\dots,S_n$, admissible expected return vectors satisfy
   $$
   r_1\ge r_2\ge \cdots \ge r_n.
   $$
   More generally, the information set is a convex cone $Q\subset\mathbb R^n$ of all mean vectors consistent with the sort or other order restrictions.

2. **Risk and relevant return component**

   For portfolio weights $w$, risk is
   $$
   \sigma^2(w)=w^\top V w.
   $$
   Since the sort contains only relative-return information, the expected-return comparisons are meaningful only up to the direction orthogonal to the all-ones vector $1$. The paper therefore works with the “relevant” component of the portfolio that prices ordered return differences, not the absolute level of the mean.

3. **Preference relation**

   Fix a risk budget $\sigma^2$. A portfolio $v$ is preferred to $w$ if, for every admissible $r\in Q$, the expected return of the relevant component of $v$ is at least that of $w$, and for some admissible $r$ it is strictly larger. This is the sort-based analogue of mean-variance efficiency.

4. **Single complete sort: basis of difference portfolios**

   Define vectors
   $$
   E_j=\frac1n(\underbrace{n-j,\dots,n-j}_{j\ \text{entries}},\underbrace{-j,\dots,-j}_{n-j\ \text{entries}}),\qquad j=1,\dots,n-1.
   $$
   These form the canonical exposures to adjacent return-order differences. If
   $$
   y=x_1E_1+\cdots+x_{n-1}E_{n-1},\qquad x_j\ge 0,
   $$
   then $y$ has decreasing coordinates and sum zero. The paper proves that the efficient portfolios are precisely
   $$
   w\propto V^{-1}y
   $$
   for some such nonnegative combination $y$.

5. **Characterization theorem**

   For the single complete sort, the efficient set is exactly the set of portfolios that are mean-variance optimal for expected-return vectors $r$ satisfying
   $$
   r_1\ge r_2\ge \cdots \ge r_n,\qquad \sum_{i=1}^n r_i=0.
   $$
   Equivalently, if $r=Vw$ violates monotonicity or zero-sum consistency, then $w$ is not efficient: there exists another portfolio $v$ with the same risk and strictly better exposure to all admissible orderings.

   This is the core exact result. It does **not** say every portfolio is efficient for some $r$; that is trivially true with $r=Vw$. It says the efficient portfolios are those for which the implied $r$ belongs to the sort cone intersected with the zero-sum hyperplane.

6. **Proof idea**

   The proof uses dual-cone geometry. Since any portfolio is Markowitz-optimal for $r=Vw$, efficiency reduces to whether $Vw$ lies in the cone generated by the difference basis $\{E_j\}$. If not, there exists a feasible perturbation in the dual cone that raises return for every admissible $r\in Q$ while preserving risk level after rescaling. The paper refers to a longer companion manuscript for the full convex-analysis proof, but the structural statement is exact.

7. **Choosing a unique optimal portfolio: the centroid**

   The efficient set is still a continuum. To select a single portfolio, the paper defines a centroid vector $c$ representing the average direction of the admissible cone. The chosen portfolio solves
   $$
   \max_w\ w^\top c
   \quad\text{subject to}\quad
   w^\top V w\le \sigma^2.
   $$
   This is a linear objective with a quadratic constraint. The solution is the “centroid optimal portfolio.” For a single complete sort, the centroid has a closed approximation using normal-score-like formulas.

8. **Multiple sorts and sectors**

   The same construction generalizes to:
   - multiple sector sorts,
   - incomplete sorts,
   - several simultaneous ordering criteria.

   The key object remains the cone $Q$ of admissible means. Once $Q$ is specified, the efficient set and centroid portfolio follow from the same geometric logic.

9. **Empirical claim**

   The empirical section argues that portfolios built from reversal sorts plus covariance information outperform simpler sort-based heuristics. This is an empirical add-on, not part of the proof theory.

# 5. Domain of applicability

- The method applies when the investor is willing to specify only order information, not cardinal return forecasts.
- It is especially useful when sorts come from anomalies or signals that are believed directionally but not metrically.
- The theory relies on a covariance matrix $V$, so it is not “distribution free”; only the mean side is replaced by an order cone.
- The strongest exact characterization is for a single complete sort. Broader information structures are conceptually handled by the same cone method, but the paper’s cleanest theorem is in the complete-sort case.
- The novel contribution is the order-cone preference relation and its exact identification with a restricted Markowitz efficient set.


## 6. Source version and the portfolio space

The local source is the 22-page manuscript dated **26 April 2005**. It presents intuition, constructions, and empirical illustrations while referring substantial proofs to the companion manuscript *Optimal Portfolios from Ordering Information* (2004). Assertions attributed to that companion are not full proofs reproduced in the present PDF.

Positions are dollar amounts that may be positive or negative; uninvested wealth is held in cash. In the clean characterization, the feasible set is the ellipsoid $\mathcal M=\{w:w^\top Vw\le\sigma^2\}$, with positive-definite $V$ so that the inverse and finite risk normalization exist. There is no simultaneous constraint $\mathbf1^\top w=1$ in that particular closed-form problem. Adding full investment, long-only bounds, turnover, or neutrality changes the optimization even though the centroid can still be used as a linear objective.

A complete sort contains no information about the common level of expected returns: adding $a\mathbf1$ to a consistent vector leaves every ordering unchanged. The authors consequently remove the corresponding irrelevant direction from preference comparisons. This is a modeling choice, not the same as insisting that the dollar return of one portfolio exceeds another for every mean vector with an arbitrary common level. The latter comparison would require equal total dollar exposure.

The distinction also means that $\mathbf1^\top c=0$ does not in general imply $\mathbf1^\top V^{-1}c=0$. A covariance-adjusted centroid portfolio may have a nonzero net dollar position. Dollar neutrality requires an explicit constraint or a special covariance structure. Calling every portfolio generated by this theory automatically market neutral or dollar neutral would be incorrect.

## 7. Fundamental portfolios, dual directions, and efficiency

For a complete sort, the fundamental dollar-neutral trade is $e_j$ with a +1 position in stock $j$ and −1 in stock $j+1$. Its expected return is the ordered spread $r_j-r_{j+1}\ge0$. Nonnegative combinations of these trades have nonnegative expected returns whenever the sort is correct.

Every difference portfolio can be decomposed as

$$
w-v=\sum_{j=1}^{n-1}\lambda_j e_j+\gamma\mathbf1.
$$

The coarse preference compares the signs of $\lambda_j$ and ignores $\gamma$. Thus it is a partial order on relevant exposures: mixed positive and negative coefficients need not be comparable. The benefit is a conclusion that does not require numerical forecasts for the adjacent spreads. The cost is that the relation alone usually leaves many efficient portfolios.

The vectors $E_j$ introduced earlier are dual to the adjacent-spread trades: $E_i^\top e_j=\delta_{ij}$ and $E_i^\top\mathbf1=0$. Therefore a vector

$$
y=\sum_j x_jE_j,\qquad x_j\ge0,
$$

has adjacent differences $y_j-y_{j+1}=x_j$ and zero sum. This gives a concrete parameterization of the sorted, zero-mean cone. With a pure variance budget, a nonzero such $y$ yields

$$
w(y)=\frac{\sigma V^{-1}y}{\sqrt{y^\top V^{-1}y}}.
$$

The scaling, omitted by proportionality notation, is necessary to compare portfolios at the same ex ante risk. The source's characterization says these are precisely the efficient directions under its coarse preference and risk set. Positive multiples of $y$ produce the same normalized portfolio, so the correspondence is naturally between rays of mean vectors and risk-normalized portfolios, rather than a literal one-to-one mapping of all vectors with arbitrary magnitude.

The construction does not assert that the highest-ranked stock must have the highest final weight. Covariances can make a lower-ranked asset useful for hedging or lead to a short position that offsets an otherwise risky combination. The ordering applies to the imputed return direction $Vw$, not necessarily to $w$.

## 8. The extra assumption behind a unique centroid portfolio

The efficient set does not itself identify one portfolio. The authors add a symmetry assumption over possible expected-return directions. Within the relevant cone, directions are treated without a preferred angular orientation, using a radially symmetric measure. The centroid is defined with respect to that construction; the unbounded cone does not have a finite unnormalized “uniform average” under ordinary Lebesgue measure.

This step introduces more structure than ordinal dominance alone. The paper motivates a finer preference by the fraction of compatible directions for which one portfolio's relevant component outperforms another and attributes its representation by a centroid linear functional to the companion analysis. The present manuscript does not supply the full argument or all general conditions needed for that representation. In particular, one should not generalize it into a theorem that majority comparisons under every arbitrary distribution on every cone are automatically transitive or represented by the distribution's ordinary mean.

Once the centroid $c$ is specified, the computational problem is unambiguous:

$$
\max_{w\in\mathcal M}c^\top w.
$$

With only the ellipsoidal risk budget, its solution is $\sigma V^{-1}c/\sqrt{c^\top V^{-1}c}$. With linear restrictions and a variance bound, it is a convex quadratically constrained or second-order cone problem. The manuscript sometimes calls it a linear program because the objective is linear; with a quadratic constraint it is not an LP in the usual optimization classification.

For a complete sort of $n$ assets, the source provides the approximation

$$
c_{j,n}\approx\Phi^{-1}\!\left(\frac{n+1-j-\alpha}{n-2\alpha+1}\right),
\qquad
\alpha=0.4424-0.1185n^{-0.21}.
$$

Its reported approximation accuracy is within about one-half percent in the setting analyzed. It places relatively more magnitude at extreme ranks than a linear rank score. The overall scale is immaterial for a fixed-risk maximization; it matters if the same scores are put into an objective with a fixed risk-aversion coefficient instead.

## 9. Information structures that differ economically

Within-sector sorts convey no ranking of sector-level expected returns. Their irrelevant subspace is larger than the single common-level direction of a global sort. Treating each sector's top-ranked stock as numerically identical to the top stock in another sector imposes an additional cardinal convention; the paper's cone geometry supplies its own relative scaling.

Grouped or decile information orders groups without ranking all members inside a group. The centroid for ten groups of five stocks is consequently not generally identical to taking a ten-stock centroid and repeating each entry five times without adjustment. Additional information that the first $\ell$ names have positive expected returns and the rest negative also changes the cone because zero now has economic meaning.

The manuscript allows inequalities about spread sizes, such as $r_1-r_2\ge r_2-r_3$, and discusses multiple indicators. Conflicting full sorts cannot simply all be imposed as strict beliefs without consequence: their intersection may force many means equal. The source says its broader framework treats conflicting information, but delegates technical implementation to the companion work. This short article does not provide a general plug-and-play recipe for learning confidence weights for conflicting value and momentum signals.

## 10. Historical experiment and reported results

The CRSP study begins with the 1,000 largest-capitalization stocks on 19 January 1990 that have at least 1,000 preceding daily observations. The universe is followed to 31 December 2002. Departing stocks are replaced by the largest new eligible names, yielding about 3,000 daily returns and roughly 2,000 distinct stocks over the study. The intended construction avoids selecting a universe solely from survivors at the end of the sample.

Every day the covariance matrix is estimated from the preceding 1,000 daily observations. Stocks are ranked by reversal over a past return window, with the most negative past returns ranked highest for future expected returns. The illustrations consider reversal windows of 5, 10, 15, 20, and 25 days and implementation lags of zero or one day. Portfolios rebalance daily.

Four constructions separate the effect of scoring from the effect of covariance adjustment:

| Score and optimization | Portfolio direction |
|---|---|
| Linear rank weights | $\ell$ |
| Centroid rank weights | $c$ |
| Covariance-adjusted linear scores | $V^{-1}\ell$ |
| Covariance-adjusted centroid scores | $V^{-1}c$ |

All are scaled to unit ex ante risk under the estimated covariance. This is a fairer risk comparison than comparing raw dollar weights, but it does not guarantee identical realized volatility.

For 500 stocks and a five-day reversal window, Table 2 reports zero-lag information ratios of approximately 2.97, 3.22, 5.82, and 6.88 for these four constructions. With a one-day lag, the corresponding values are 2.72, 2.84, 3.55, and 4.20. Thus much of the improvement comes from using covariance, and the centroid adds further improvement in this example. The decline with lag also reveals sensitivity to how quickly the short-horizon reversal signal is traded.

The authors summarize simulations in which random permutations degrade a known ranking and say performance declines gradually. The detailed simulation protocol and complete numerical evidence are not given in this short presentation, so the summary should not assign a quantitative robustness threshold absent from the PDF.

## 11. Limits and implementation implications

The reported historical comparison does not establish net performance after commissions, bid–ask spreads, borrow costs, and market impact. Daily rebalancing and immediate close-based implementation are especially material for reversal strategies. A one-day delay helps expose timing sensitivity, but does not itself model execution costs or guarantee that a closing-price signal can be traded at that same close.

The method still requires reliable covariance estimation. At 500 assets and 1,000 daily observations, estimation noise and eigenvalue instability can matter; ordinal means do not eliminate covariance risk. Shrinkage, factor risk models, position limits, and turnover constraints are reasonable extensions, but their performance is not proved by the reported unconstrained inverse-covariance experiment.

Finally, the cone can be wrong. The nonnegative-spread guarantees are conditional on the ranking of expected returns, not guarantees for realized returns and not protection against ranking errors. The contribution is a disciplined translation of stated ordinal beliefs into risk-aware allocations, with an explicit additional symmetry convention for choosing among efficient portfolios. Its empirical advantage is evidence from the specified reversal experiment, not a general dominance theorem over all numerical alpha models.
